# 操作設定（Issue #41）

準備画面 → 設定。変更ボタンを選んでキーまたはマウスボタンを入力。Escで取消。重複は拒否し、既存の使用先を表示する。スライドはShift、ダッシュはCtrlを初期値とする。移動・ジャンプ・射撃・照準・リロード・スキル1（Q）・スキル2（E）も変更可能。

マウス感度0.2〜3.0、自動リロードの有効/無効、初期設定復元。変更はuser://controls.cfgへ即時保存。保存失敗時は画面に表示し、実行中の反映は維持。進行データとは別管理。HUDと準備画面の両スキルキー表示も設定に追従。旧スキルキーの設定は保持し、旧設定でEが使用済みの場合はスキル2に空きキーを割り当てる。Escは固定。

control_settings.gdは入力設定とInputMap、control_settings_view.gdは設定UIを担当。設定ロードはプレイヤー生成前。キーボードは物理キーによる割当。

検証：control_settings_test（初期キー、重複拒否、キーボード/マウス変更、保存・再読込、初期化）、run_result_flow_test、weapon_runtime_test。テスト保存先は/tmp、ユーザーの設定は書き換えない。
