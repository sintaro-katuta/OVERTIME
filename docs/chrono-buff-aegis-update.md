# クロノとイージスの更新

Issue: https://github.com/sintaro-katuta/OVERTIME/issues/48

[2種類の動画（約14秒・音あり）](screenshots/skills-field/update.mp4) / [全6種類のギャラリー](skills-appearance-gallery.html)

## クロノフィールド

前方約4mの地面へ設置する半径6m、5秒の自己強化領域。範囲内では連射速度1.5倍、範囲外・終了・ステージ遷移で解除。再入場すると再適用する。高低差3m以内が対象。足場が見つからなければ不発でクールダウンを消費しない。再使用は12秒。

通常の連射強化に乗算し、通常射撃・ボルト動作・バースト間隔へ適用する。出入りによって恒久倍率は書き換えない。敵や敵弾の減速は廃止した。

金色の床面リング、回転するコアと軌道、境界の光を追加。領域は設置位置に残り、範囲内では画面上に「連射ブースト ×1.5」を表示する。

## イージス

ユーザー提供のシグマの盾の画像を参考に、青い半透明の面、明るい縁、角の丸い横長の輪郭へ変更。カメラ正面1.65m、幅3.2m、高さ1.9m、角半径0.3m。見た目と弾の遮断範囲に同じ角丸形状を使用し、切り取られた角の外側は弾が通過する。

盾越しに敵が見え、被弾位置に波紋が広がる。従来どおりプレイヤーに追従し、正面から盾を横切る敵弾を遮断。背面・側面の全方向防御ではない。持続4秒、再使用10秒。

## 検証

Godot 4.6.3で以下がPASS。

- `chrono_buff_shield_test.gd`: 範囲内・外・再入場・高さ・期限・固定設置、実射撃間隔、通常強化との併用と倍率の累積防止、敵減速廃止、盾の中央・縁・角・背面、リセット。
- `skill_system_test.gd`: 取得抽選・取得固定・各スキルの作用と終了。
- `skill_effects_test.gd`: 発動音、描画状態、ポーズ、期限、遷移時の後始末。
- `skill_recall_test.gd`: 牽引と巻戻しの回帰。
- `weapon_runtime_test.gd`: 9武器、射撃モード、弾道、ダメージ、ADS、リロード。
- `skill_motion_preview.gd -- --field-preview`: 実描画432フレームを撮影。青い膜越しの視認性と金色の設置表示を目視確認。動画のデコードとギャラリーのリンクを検証。

動画は固定した敵配置と自動入力による演出確認。連射倍率1.5は初期値で、遊んだときの強さ・気持ちよさはプレイのフィードバックで調整する。
