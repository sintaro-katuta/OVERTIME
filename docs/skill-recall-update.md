# グラップル反転 / リワインドの帰還動作

Issue: https://github.com/sintaro-katuta/OVERTIME/issues/46

[2種類の更新動画（音付き約18秒）](screenshots/skills-recall/update.mp4) / [全スキル一覧](skills-appearance-gallery.html)

## グラップル

命中した敵をプレイヤー正面の約2mへ引き寄せる。プレイヤーは牽引されず、通常の移動/射撃/スライドを続けられる。到達後1.5秒の追撃受付と+2秒ボーナスは維持。敵のAI移動・射撃は牽引中に止める。チェーンの射出に合わせて75ms後に引き始め、最大1.3秒で解除。再使用2.5秒、射程32mは維持。

実カプセルで衝突を判定し、歩ける地面は滑り、壁で中断。対象消滅やステージ終了で解除する。牽引後の敵は移動/攻撃を再開する。

## リワインド

参考はユーザー指定の[トレーサーのリコール](https://overwatch.blizzard.com/ja-jp/heroes/tracer/)。今回は位置と動きの変更で、ライフ/弾薬回復など他ゲームの能力仕様は追加していない。

40ms間隔で直近の位置を記録し、直前3秒分の経路を0.8秒の加減速付き逆再生でたどる。最初から到着点へ瞬間移動しない。高速なフレームでも各曲がり角の記録を通過し、斜めに近道しない。

帰還中は武器と照準を一時的に隠し、周辺の逆流と視野角の変化を出す。通常移動/視点入力/射撃/リロード/再発動を停止。ランタイマーは進み、弾薬・時間・敵の状態は戻らない。無敵は追加していない。

地形の補間誤差で足元に引っ掛からないよう、経路を8cm浮かせて再生し、終点で記録位置へ下ろす。移動区間ごとに実カプセルをスイープし、新しい壁で停止。準備/結果/ステージ遷移で経路と演出を破棄し、武器表示を復元する。

## 検証

- `skill_system_test.gd`: プレイヤー静止のまま敵が正面へ到達、追撃受付、巻戻し終了、既存の抽選・他スキルを確認。
- `skill_recall_test.gd`: 曲がり角の中間点を通過、発動時に瞬間移動しない、経路に新しい壁があれば停止、時間の通常経過と弾薬保持、操作抑止、ポーズ/リセット、武器表示復元、牽引の壁/対象消滅を確認。
- `skill_effects_test.gd`, `stage_exit_test.gd`, `player_slide_test.gd`, `weapon_runtime_test.gd`: PASS。
- `skill_motion_preview.gd -- --recall-preview`: 草原で2種類を自動操作。敵が到達して追撃受付になること、帰還後の位置が記録位置に戻ることをassert。537フレーム/30fps、17.9秒の録画が完走。巻戻し中の武器非表示と視点の逆移動を描画確認。
- 初回録画で地面を壁扱いして中断するケースを確認し、地面への追従と帰還時のクリアランスを修正して再検証。
- 全更新動画のデコードとギャラリーの参照先を検証。`git diff --check` PASS。

プレビューではスキル/敵配置を固定し、グラップル後の撃破をテストから発生させる。リワインドの録画は発動前の通常移動と発動後の帰還を字幕で区別している。通常ランの取得制限は変更していない。
