# アクティブスキル

Issue: https://github.com/sintaro-katuta/OVERTIME/issues/69 （初期実装: #43）

## 事前装備（Issue #69）

準備画面の「スキル」で既存6種類から異なる2種類を選択する。0個・1個・重複装備では出撃できず、準備画面からスキル選択へ案内する。ラン中の変更は禁止。ステージ出口のランダム取得は廃止し、通常強化報酬だけを提示する。

スキル1はQ、スキル2はEで発動。どちらも設定画面から変更でき、HUDと準備画面のキー表示も追従する。旧Q設定（内部アクション名grapple）は引き継ぐ。旧設定でEが別操作に使われている場合は既存割り当てを保持し、スキル2には空きキーを割り当てる。

装備選択はuser://skill_loadout.cfgへ保存し、リトライ・次回起動でも保持する。初回は未装備。未完成の選択も保存し、保存失敗は画面に表示する。リトライでは両枠のクールダウンと展開効果をリセットする。

クールダウンと継続効果はそれぞれ独立し、例えばクロノとイージスを併用できる。リワインド中はどちらの枠も新たに発動できず、射撃・リロードも停止する。既に展開した効果は継続する。HUDには両スキルのキー、名前、展開状態、残りクールダウンを表示する。

| スキル | 効果 | 再使用 | 演出 |
|---|---|---|---|
| グラップル | 照準内32mの敵をプレイヤー正面約2mへ牽引。到達から1.5秒以内の対象キルに+2秒（従来のコンボ倍率適用） | 2.5秒 | 発射装置、金属チェーン、発光フック、火花、巻取り、追撃マーカー |
| リパルス | 前方7mの敵を押し出す。下向きに発動すると跳躍。遮蔽物の向こうへは作用しない | 6秒 | 橙の衝撃リングと飛散火花 |
| リワインド | 直前3秒の経路を約0.8秒で逆再生。巻戻し中は通常移動/射撃を停止。時間・弾薬・敵は戻さない。記録不足はCD消費なし。経路に新しい壁がある場合は手前で停止 | 10秒 | 経路を逆走する視点、人型の残像、武器の一時非表示、周辺の逆流とFOV変化 |
| ボルテックス | 前方最大15mへ装置を投射し、半径7mの敵を4秒間引き寄せる。壁越しの引力なし | 10秒 | 紫の回転リング、中心へ流れる粒子、発光コア |
| クロノフィールド | 前方約4mの地面に半径6m、5秒の領域を設置。範囲内の自分の連射速度が1.5倍。外へ出ると解除、再入場で再適用。通常強化とは乗算 | 12秒 | 金色の設置コア、範囲リング、回転軌道、連射ブーストHUD |
| イージス | 4秒間、カメラ正面1.65mに幅3.2m・高さ1.9m、角半径0.3mの盾。前方から盾面を横切る敵弾を遮断。側面・背面は防げない | 10秒 | 青い半透明膜、明るい縁、着弾波紋と火花 |

スキル形状と短い発動音はGodot内で生成するため、専用の外部モデルや音源は不要。VFXはスキル別の色、発光マテリアル、形状粒子で表現する。全画面点滅や照準を隠す不透明な面は使わない。事前選択画面は左に6種類の名前だけのリスト、右に選択スキルの効果説明・再使用時間・実挙動の動画・装備操作を表示する（Issue #70）。動画は無音で自動ループし、一時停止/再開が可能。選択を切り替えると対応する動画を先頭から再生する。上部のQ/E枠表示は置かず、動画の下に「Qに装備」「Eに装備」を並べて装備先を直接選ぶ（キー変更に追従）。装備中のボタンから解除できる。同じスキルをもう一方の枠に重複装備する操作は無効。装備・解除では動画を中断しない。画面を離れると再生を停止する。

`gameplay/skills/` にカタログ、単体コントローラ、2枠の装備管理（skill_loadout.gd）、VFX、事前選択UIを分離。`main.gd` は入力、敵/敵弾への作用、報酬/遷移に接続。既存の空中キル報酬が実弾の命中処理で常に無効になっていた箇所も接続し、リパルス跳躍からの撃破に適用する。

ステージ終了/移動/結果/準備への遷移で展開効果・履歴・ノックバック・チェーンを破棄。装備済みの2スキルは次ステージへ持ち越す。ポーズではスキルの時間・VFX更新を止める。

## 検証

Godot 4.6.3。`--headless --log-file /tmp/<name>.log --path . --script tests/<test>.gd` で実行。

Issue #69の検証:

- `skill_loadout_test.gd`: 2個必須、重複拒否、保存/読み込み、Q/E入力、独立CD、クロノ/盾の同時効果、ポーズ、取得抽選なし、リトライ、2枠目リワインドの入力制限、2枠目グラップルの単一更新とチェーン表示。
- `preparation_launch_test.gd`: 0個/1個で出撃不可、6項目の名前リストと動画表示領域、設定UIでスキル2を変更、2個装備後の出撃。
- `control_settings_test.gd`: 両枠の初期キー、重複拒否、保存/読み込み、旧設定でEが使用済みの場合の移行。
- `skill_system_test.gd`、`skill_recall_test.gd`、`skill_effects_test.gd`、`chrono_buff_shield_test.gd`: 既存6種類の効果・衝突・演出・時間停止/再開。
- `run_result_flow_test.gd`、`weapon_runtime_test.gd`、`stage_exit_test.gd`: リトライ、武器、10ステージの通常報酬/出口遷移。
- `skill_loadout_capture.gd`: 描画ありで選択・出撃準備・設定・2枠HUDを保存して目視確認。

各CD/効果量は既存値を維持する。楽しさ・難易度の最終調整は実プレイのフィードバックをもとに行う。

グラップル反転とリコール風の帰還動作は[更新仕様と検証](skill-recall-update.md)を参照。

クロノの自己連射強化と青いイージスは[更新仕様と検証](chrono-buff-aegis-update.md)を参照。

表示確認: [スキル選択](screenshots/skill-loadout/skill-loadout-selection.png)、[出撃準備](screenshots/skill-loadout/skill-loadout-preparation.png)、[設定](screenshots/skill-loadout/skill-loadout-settings.png)、[2枠HUD](screenshots/skill-loadout/skill-loadout-hud.png)。

`skill_selection_video_test.gd` は6種類の動画デコード、説明/動画の対応、名前のみの一覧が画面内に収まること、閲覧時の装備維持、一時停止/再開、実際のEOFでのループ、詳細内からQ/E枠への直接装備・置換・解除、変更キー名の表示、重複禁止、保存、離脱時の停止を検証。headlessと描画ありの両方でPASS。`preparation_launch_test.gd` と `skill_loadout_test.gd` もPASS。

## mainへの統合確認

統合時は既存mainの2ステージ構成を基準に、スキル・設定・準備画面・HUDと実行に必要な依存だけを分離して確認した。別件のステージ拡張・武器モデル・揺れの未コミット変更は含めない。上記10ステージの検証は開発作業ツリー上の履歴。統合用の独立チェックアウトではスキル・出撃・動画・リトライ・武器の10本のテストがPASSし、動画選択画面を描画ありでも確認済み。
