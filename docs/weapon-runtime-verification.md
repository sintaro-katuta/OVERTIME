# 武器の向き・基本性能の修正（Issue #16）

## 表示確認

Godot 4.6.3 / macOS OpenGL で全9武器と Obsidian Circuit スキンを、腰だめ・ADS の計20画面で描画確認した。

- 初期解放 Vanguard 5.56 と Sidearm 9 のモデル回転・位置・スケールおよび腰だめ/ADS位置は保持。
- 追加7武器とスキンは Styloo モデルの +X が銃身方向。Y回転90度でカメラの -Z へ合わせた。
- GLBの先端頂点から銃口座標を測定。モデルごとのスケールとADS位置は `gameplay/weapon_visual_profile.gd` に分離。
- スコープ等が不透明な追加モデルでは、その上に中央クロスヘアを残す。初期Vanguardのアイアンサイト表示は維持。

再現コマンド（描画可能な環境が必要、プレイヤーのセーブは読み書きしない）：

```sh
Godot --path . --script tests/weapon_visual_capture.gd -- /tmp/overtime-weapons.png
```

一覧の各行は Vanguard / Kestrel / Bastion / Sentinel / Sidearm / Viper / Longshot / Marksman / Breach / Vanguardスキン、左が腰だめ、右がADS。

## 性能

`WeaponCatalog` から射撃方式、発射間隔、ボルト周期、散弾数、弾速、重力、射程、距離減衰、ヘッド倍率、ADS、リロードを接続した。

- フルオートのみ押し続けて連射。単発・ボルト・ポンプは押すたびに1発。バーストは押すたびに3発、弾切れ・リロード時は残バーストを解除。
- 散弾は8方向へ発射し、1射撃で消費する弾薬は1発。
- 射程は移動距離で制限し、最後の移動区間も衝突判定する。壁・敵への貫通を防止。
- ヘッドショットの無条件撃破を廃止して最終ダメージを適用する。命中ダメージと同値のXPを付与。
- 旧HP2/3では全武器が1発撃破になるため、Issue #8 の100 HP基準へ修正。Rangerは旧比率1.5倍を維持して150 HPとした。
- 反動は武器モデルと視点のpitch/yawに適用し、入力した視点方向を保ちながら回復。
- 弾倉式の手動リロードは残弾破棄、チューブ式は残弾維持と1発ずつの装填。弾切れ時は自動リロード。
- 準備画面の設定から自動リロードを無効化できる。設定は起動中のみ保持する。

カタログが定性的な反動役割と相対拡散倍率だけを持つため、基準値をCombatProfileにまとめた。腰だめ拡散半角は近距離1.5度・中距離0.8度・精密0.5度、散弾半角4度。ADSは既存倍率を適用する。これらの体感バランスの長時間試遊は未実施。

## 検証

`tests/weapon_runtime_test.gd` が実ゲームシーン上で全武器の銃口方向、初期表示維持、射撃方式、散弾、ボルト周期、弾速・重力・射程、距離減衰、ADS、リロードを検証。物理空間で壁の非貫通、敵HPの減少、ヘッドショットXPも確認。

既存の武器・進行・準備画面・終了画面を含む12テストが成功。`git diff --check` も成功。

アタッチメント効果の戦闘反映は別Issueで扱う。既存の効果・トレードオフのデータ自体は変更していない。
