# OVERTIME — Godot 4 Vertical Slice

GDD v0.2を基にした、箱プロトタイプです。アセットを作り込む前に、時間を稼ぐ高速FPSのコアが楽しいか検証します。

## 起動

Godot 4.6以降でこのフォルダをインポートし、`main.tscn`を実行します。

## AIエージェントとの開発

タスクの正本は GitHub Issue です。Issue Form と並列作業のルールは
[AGENTS.md](AGENTS.md) にあります。AI は `status:ready` の Issue に記載された目的、背景、
スコープ、完了定義を基に実装を進め、進捗と結果を Issue に記録します。

## 操作

- `WASD`：移動
- `Space`：ジャンプ
- `Shift`：ダッシュ
- 左クリック（ホールド可）：射撃
- 右クリック：照準（ADS）
- アサルトライフルとピストルは、それぞれ一人称用の腰だめ／照準ポーズへ移行
- `R`：リロード（ラン終了後は再起動）
- `Q`：Grapple（獲得後）
- `Esc`：ポーズ／再開

## 含まれる縦切り

- 残り30秒の寿命タイマーと、ステージごとのTime Cap
- 一人称表示のローポリPulse Rifle、通常キル／ヘッドショット／空中キルの時間報酬
- ステージ突破時は、無料スキル2種と時間を支払う高出力スキル1種から選ぶランダムな報酬選択。Grapple、連射／時間報酬、防御、ダッシュなどのスキルを取得可能
- Stage 1（8体）→ ロードアウト選択 → 別アリーナのStage 2（14体）。ステージ開始時にプレイヤー、敵、ミニマップが次の空間へ移動
- Stage 2は紫を基調とした別空間で、遮蔽物のレイアウトも変更
- 敵弾による寿命ダメージと、回避・遮蔽物を使った生存判断
- 敵へ高速で引き寄せるGrappleと、直後のGrapple Kill（+2.0秒）
- 連続撃破で最大1.75倍まで上がる短時間コンボ
- Stage 2の遠距離敵（紫）は距離を保ち、シアン発光の攻撃予告後に高速弾を放つ
- 物理遮蔽物・低い足場・敵弾の壁衝突により、地形を使った回避と射線管理が可能
- Stage 2は2 Wave構成。前半7体を倒すと弾幕をリセットして後半7体が投入される
- 18発マガジン・予備弾薬・Ammo Cellドロップを使うリロード管理
- 通常敵は胴体2発、Rangerは胴体3発。ヘッドショットと反射弾は即撃破
- Escで敵・弾・アイテム・タイマーごと停止するポーズ画面
- ADS、移動時の武器ボブ、方向付き被弾インジケーターによる戦闘フィードバック
- 暗色空間・ローポリ・ネオンの仮アートと、角張ったロボット敵の高視認性ヘッド
- 開始準備画面の`武器`タブで、初期解放のVanguard 5.56またはSidearm 9を選択してから出撃。未解放の7武器はロック表示
